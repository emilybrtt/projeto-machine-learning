# Predição de AVC — Projeto de Machine Learning

Projeto de Machine Learning para a disciplina de Machine Learning do 4º semestre de Ciência da Computação no Insper, ministrada pelo docente Humberto Sandman e Luciano Pinheiro. Este projeto inclui análise exploratória e modelagem de classificação para predição de risco de AVC (derrame) e o grupo foi composto por Emily de Britto Gomes (emilybg@al.insper.edu.br) e Gabriel Chaves Aguiar (gabrielca5@al.insper.edu.br).

## Conteúdo

- `aps_machine_learning.ipynb` — EDA (Parte 1)
- `aps2_modelagem.ipynb` — Modelagem e classificação (Parte 2)
- `docs/` — documentação do projeto (MkDocs)
- `rubrica.md` — checklist de avaliação
